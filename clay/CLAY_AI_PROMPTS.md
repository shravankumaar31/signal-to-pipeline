# Clay AI formula prompts — Accounts v1

Paste each prompt into **"What formula would you like to create?"**. Every `/Column Name` must be a column chip:
type `/` and pick the column. Click **Regenerate**, check **Referenced columns**, and compare the preview with
the expected values before saving. Create the columns in this order — later ones use earlier ones.
"Age in days" = whole days from that date to today.

1. Exclusion — Return text. If /CRM is not empty and is not "Salesforce" and not "Unknown", return "CRM is " followed by the CRM value. Otherwise, if /Hard Exclusion is not empty, return its value. Otherwise, if /HQ Country is not "US" and not "CA", return "Legal HQ outside US + Canada (" + HQ Country + ")". Otherwise, if /Employees (exact) is greater than 5000, or /Employee Band is "5001-10000" or "10001+", return "Over 5,000 employees". Otherwise return an empty string.
2. Pts Hiring — Return a number. If /Hiring Posted is empty, return 0. Base = 25 if /Hiring Comp Specific is true, otherwise 20; then add 10 if /Hiring Pain Language is true. Half = Base divided by 2, rounded half up. If /Hiring Closed is not empty: return Half if Hiring Closed is 30 or fewer days before today, otherwise 0. Otherwise, with age = days from Hiring Posted to today: return Base if age is 45 or less, Half if age is 90 or less, otherwise 0.
3. Pts Sales Growth — Return a number from /Open Sales Roles (empty counts as 0): 20 if 20 or more, 15 if 10 or more, 10 if 5 or more, otherwise 0.
4. Pts Funding — Return a number. If /Funding Signal Date is empty, return 0. Age = days from Funding Signal Date to today. Return 20 if age is 90 or less, 10 if age is 180 or less, otherwise 0.
5. Pts Leadership — Return a number. If /Leadership Date is empty, return 0. Base = 13 if /Leadership Role is "CFO", otherwise 20. Age = days from Leadership Date to today. Return Base if age is 90 or less; if age is 180 or less return Base divided by 2 rounded half up (7 for CFO, 10 otherwise); otherwise 0.
6. Pts Competitor — Return 5 if /Competitor Mention Live is true, otherwise 0.
7. Pts Other — Return a number. If /Other Signal Date is empty, return 0. Age = days from Other Signal Date to today. Return 5 if age is 45 or less, 3 if age is 90 or less, otherwise 0.
8. Fresh Signal — Return true if ANY of these is true, otherwise false: (/Hiring Posted is not empty AND /Hiring Closed is empty AND Hiring Posted is 45 or fewer days before today); /Open Sales Roles is 5 or more; (/Funding Signal Date is not empty AND it is 90 or fewer days before today); (/Leadership Date is not empty AND it is 90 or fewer days before today); /Competitor Mention Live is true; (/Other Signal Date is not empty AND it is 45 or fewer days before today).
9. Fit — Return a number = headcount points + funding points + tool points + CRM points. Headcount points: if /Employees (exact) is a number above 0, give 8 if it is 200–1000, 4 if it is 100–199 or 1001–2000, otherwise 0; if it is empty, use /Employee Band: 8 for "201-500" or "501-1000", 4 for "51-200" or "1001-5000", otherwise 0. Funding points from /Funding Stage: 8 for "Series B" or "Series C", 6 for "Series D", 5 for "Profitable private", otherwise 0. Tool points from /Incumbent Comp Tool: 10 for "Spreadsheets", 8 for "In-house build", 5 for "Unknown", otherwise 3. CRM points: 4 if /CRM is "Salesforce", otherwise 0.
10. Intent — Return the smaller of 70 and the sum of /Pts Hiring, /Pts Sales Growth, /Pts Funding, /Pts Leadership, /Pts Competitor and /Pts Other (empty counts as 0).
11. Score — If /Exclusion is not empty, return empty. Otherwise return the smaller of 100 and /Fit plus /Intent.
12. Below ICP Floor — Return true if /Funding Stage is "Pre-seed", "Seed" or "Series A"; or /Employees (exact) is above 0 and below 100; or /Employees (exact) is empty and /Employee Band is "1-10" or "11-50". Otherwise false.
13. Signal Tier — Return text. If /Exclusion is not empty, return "Excluded". Otherwise, if /Below ICP Floor is true, return "C". Otherwise, if /Score is 60 or more AND /Fresh Signal is true, return "A". Otherwise, if Score is 35 or more, return "B". Otherwise return "C".
14. Primary Signal — Return text. If /Exclusion is not empty, return empty. Otherwise compare these in this order: "Hiring RevOps" = /Pts Hiring, "Leadership Change" = /Pts Leadership, "Funding" = /Pts Funding, "Sales Team Growth" = /Pts Sales Growth, "Competitor Mention" = /Pts Competitor, "Other" = /Pts Other. Return the name with the most points; on a tie return the one that comes first in this order; if all are 0, return empty.
15. Score Check — Let T = /Signal Tier, plus " (capped)" when /Below ICP Floor is true and /Exclusion is empty. Return "OK" if T equals /Expected Tier, AND /Score as text (empty if empty) equals /Expected Score as text, AND (Exclusion is not empty OR /Primary Signal equals /Expected Primary). Otherwise return "MISMATCH: expected " + Expected Tier + " / " + Expected Score + " / " + Expected Primary.
